# Particle Tracking Research

## Overview

This project explores particle tracking and track reconstruction in high-energy particle physics. The goal is to investigate how tracking algorithms perform under challenging conditions, such as increasing event complexity and detector measurement uncertainty. This project also aims to mimic certain properties of the environemnts at the CERN experiments like ATLAS and CMS.

## Research Question

At what pileup densities does an Extended Kalman Filter (EKF)-based tracker begin to lose reliable state estimation, and which state variables or measurements fail first?

*Research question is preliminary and may be refined as the simulation develops*

## Structure
 - C++ — simulation and algorithm implementation
 - PYTHIA - particle collisione event generation
 - Geant4 - planned detector simulation
 - ACTS - planned track reconstruction framework
 - Python - reconstruction efficiency analysis
 - Git & Github - version control and project documentation
 - WSL/Ubuntu - development environment
